# Web Logisim

Браузерный редактор и симулятор цифровых схем: компактная библиотека и таблица свойств слева, белое поле с сеткой, отдельные инструменты редактирования, проводки и переключения входов. Ориентир для взаимодействия — [классический Logisim](https://logisim.app/).

## Запуск

```sh
npm start
```

Откройте http://localhost:5173. Для сервера требуется Python 3; сборка и внешние библиотеки не нужны. Для проверок симулятора и маршрутов: `npm test` (Node.js 22+).

### Docker

Из корня проекта выполните:

```sh
docker build -t web-logisim .
docker run --rm -p 127.0.0.1:5173:80 web-logisim
```

Откройте http://localhost:5173. Контейнер раздаёт статические файлы через Nginx; Node.js и Python на хосте не требуются. Автосохранение схем остаётся в браузере. Для остановки нажмите Ctrl+C.

## Компоненты и управление

Поддерживаются AND, OR, XOR, NOT, NAND, NOR, n-MOS и p-MOS, входы и выходы.

У AND, OR, XOR, NAND и NOR число входов задаётся свойством компонента: от 2 до 32, по умолчанию 2. Входы идут сверху вниз с шагом 20, корпус вентиля растёт вместе с ними. AND, NAND, OR, NOR, XOR считают сигнал по всем входам: AND даёт 0 при любом нуле, OR — 1 при любой единице, XOR — чётность единиц. Неподключённый вход даёт Z и никогда не превращается в 1. При уменьшении числа входов провода к исчезнувшим пинам удаляются.

- Выберите компонент слева, затем нажмите на поле для размещения. Удерживайте Shift для нескольких экземпляров; Escape отменяет размещение.
- **Выбор (1):** перемещайте элементы или участки проводов. ЛКМ по пустому месту и протягивание рисуют рамку выделения: берутся все компоненты и провода, которых рамка касается. Shift дополняет выделение, Ctrl/Cmd+A выделяет всё, Escape снимает его. Перетаскивание любого выделенного элемента перемещает всю группу, Delete удаляет её целиком. Двойной щелчок по входу переключает 0/1.
- **Входы (2):** один щелчок по входу переключает 0/1. Кнопки в панели «Сигналы» работают в любом режиме.
- **Провод (3):** нажмите на пин, задайте промежуточные точки на поле, завершите на пине противоположного типа. Можно также протянуть соединение между пинами. Новый провод заменяет прежнее подключение выбранного входа.
- Для ответвления в режиме «Провод» нажмите на существующую линию и завершите на входе. Ответвление подключено к тому же выходу; его маршрут редактируется независимо. Электрические соединения определяются подключениями пинов: простое пересечение линий не соединяет разные сигналы. Точки показывают T-соединения одного сигнала.
- У выбранного провода перетаскивайте круглые точки; двойной щелчок удаляет точку. Свойства позволяют сбросить маршрут или переподключить вход. Escape отменяет переподключение, сохраняя старый провод.
- Свойства компонента меняют метку, а у AND, OR, XOR, NAND и NOR — число входов.
- **Обзор (4):** перетаскивайте поле. Также работают пробел с перетаскиванием или средняя кнопка мыши. Колесо меняет масштаб; ⛶ показывает всю схему.
- Delete удаляет выбранное, Ctrl/Cmd+Z отменяет, Ctrl/Cmd+Shift+Z повторяет. Ctrl/Cmd+S скачивает JSON.

Меню «Файл» содержит создание, импорт и экспорт схем. Меню «Примеры» — полусумматор и RS-триггер на двух NOR. Автосохранение браузера и JSON сохраняют также состояние симуляции. История ограничена 100 изменениями.

## Проверка RS-триггера

1. Откройте **Примеры → RS-триггер на NOR**. Изначально R=1, S=0, Q=0.
2. В инструменте **Входы** выключите R. Q остаётся 0.
3. Включите S: Q становится 1. Выключите S: Q остаётся 1.
4. Включите R: Q становится 0. Выключите R: Q остаётся 0.

Симулятор начинает распространение с предыдущего состояния, поэтому обратная связь сохраняет память. Перемещение, масштабирование и изменение меток не запускают логический пересчёт. Undo/redo восстанавливают схему и состояние вместе. На паузе изменения входов применяются при продолжении симуляции.

Меню **Симуляция → Сбросить состояние** возвращает внутренние выходы в X и пересчитывает схему. Для триггера с обоими неактивными входами начальное состояние неопределено — подайте S или R. Одновременная активация обоих входов RS-триггера запрещена; при одновременном снятии в симметричной цифровой модели возможны колебания, которые помечаются X. Повторная корректная установка или сброс восстанавливает определённое состояние. Независимые части схемы продолжают работать.

## Модель и границы реализации

Четыре значения: 0, 1, Z (нет сигнала), X (неизвестно). Логические вентили пересчитываются дискретными шагами до устойчивого состояния; повторяющийся цикл означает колебания. Это логическая модель без физических задержек.

Транзисторы — однонаправленные цифровые ключи с входами G (управление), S (сигнал) и выходом справа. n-MOS открыт при G=1, p-MOS при G=0. Закрытый ключ выдаёт Z. Нет аналоговых токов/напряжений, двунаправленной проводимости и общей шины с несколькими драйверами.

Это самостоятельная реализация, а не полный порт Logisim. Вложенные схемы, многобитные шины, RAM, готовые тактовые компоненты и формат Logisim `.circ` пока не поддерживаются. JSON — собственный формат; прежние файлы проекта без сохранённого состояния продолжают открываться. Число входов вентиля хранится необязательным полем `inputs` у компонента: у старых схем его нет, и они остаются двухвходовыми.

## Проверка в браузере

`scripts/check-browser.mjs` проверяет реальные действия мышью через Chrome DevTools: RS set/hold/reset, сохранение после перезагрузки, паузу, undo/redo, размещение элементов, проводку, ответвление, редактирование маршрута, рамку выделения с групповым перемещением, Ctrl+A и удалением группы, смену числа входов вентиля с удалением лишних проводов, импорт JSON. Требуется Node.js с глобальным WebSocket (22+), запущенный сервер и отдельный тестовый Chrome:

```sh
google-chrome-stable --headless --remote-debugging-port=9222 --user-data-dir=/tmp/web-logisim-browser about:blank
npm run test:browser
```

Проверка использует localStorage **тестового профиля** и очищает его начальную схему. Не запускайте её против своего рабочего профиля. Снимок результата сохраняется в `/tmp/web-logisim-editor.png`. Адреса можно задать через `CDP_URL` и `APP_URL`.
